# 프리코스 2주차 미션 - 자동차 경주 게임
---
우아한테크코스 8기 프리코스 2주차 미션, 자동차 경주 게임을 구현한 저장소입니다.

---
## 개요
### 프로젝트 컨셉
입력받은 자동차 이름들과 시도 횟수를 기반으로 랜덤값(0~9) 에 따라 전진하거나 멈추는 자동차 경주 게임입니다.

자동차는 이름(5자 이하)과 현재 위치를 가지며 무작위로 생성된 숫자가 4 이상일 때만 전진합니다.

모든 시도가 끝난 후 가장 멀리 이동한 자동차(들) 을 우승자로 출력합니다.
잘못된 입력(이름 초과, 비어있는 값, 음수 시도횟수 등)이 들어오면 예외를 발생시키고 종료됩니다.

### 학습 목표
* 메서드는 한 가지 일만 수행하도록 분리합니다.
* 들여쓰기는 1단계까지만 허용합니다.
* else 예약어를 사용하지 않습니다.
* 3개 이상의 인스턴스 변수를 가진 클래스는 구현하지 않습니다.
* getter/setter 대신 객체의 행동으로 상태를 제어합니다.
* Randoms 및 Console API를 사용하여 외부 입출력/랜덤 로직을 처리합니다.



### 사용 라이브러리
* camp.nextstep.edu.missionutils.Randoms :
0~9 사이의 정수를 무작위로 생성 (pickNumberInRange(0, 9))
* camp.nextstep.edu.missionutils.Console :
사용자 입력값을 문자열로 받음 (readLine())

## 프로그램 흐름
**1️⃣ 입력기능**

* 쉼표(,)로 구분된 문자열로 경주할 자동차 이름을 입력받습니다.
예시: "pobi,woni,jun"
이름이 5자를 초과하면 IllegalArgumentException을 발생시킵니다.
* 시도할 횟수를 입력받습니다.
숫자가 아닌 값이 입력되면 IllegalArgumentException을 발생시킵니다.

**2️⃣ 자동차 생성 및 관리 기능**

* 입력받은 이름들로 자동차 객체리스트를 생성한합니다.
* 자동차는 이름과 현재 위치(전진 거리)를 속성으로 가집니다.
예시: Car(name="pobi", position=0)

**3️⃣ 자동차 이동 기능**

 * 0~9 사이의 랜덤 값을 생성합니다.
 * 랜덤 값이 4 이상이면 자동차가 전진합니다.

**4️⃣ 시도 횟수 별 실행 기능**

* 지정된 횟수만큼 경주를 반복합니다.
* 각 라운드마다 모든 자동차가 한 번씩 전진 여부 판단하고 매 라운드 결과를 출력합니다.

**5️⃣ 우승자 판별 기능**

* 모든 라운드가 끝난 후, 가장 멀리 이동한 자동차를 우승자로 판별합니다.
* 최댓값이 동일할 경우 여러 명을 공동 우승자로 처리합니다.

**6️⃣ 출력 기능**
* 각 라운드별로 자동차의 이름과 이동 거리를 출력합니다.
예시: pobi : ----
* 최종 우승자를 다음 형식으로 출력합니다.
예시: 최종 우승자 : pobi, jun
 
 
**7️⃣ 예외 처리** 

* 잘못된 이름 입력(5자 초과, 빈 값) 시 예외 발생 후 종료됩니다.
* 시도 횟수가 숫자가 아닐 경우 예외가 발생하고 종료됩니다.
* 시도 횟수가 0 이하일 경우 예외가 발생합니다.

## 테스트 케이스
입력 예외 상황 및 커스텀 구분자 처리를 고려한 테스트 케이스는 다음과 같습니다.

| 입력                       | 기대 결과                | 설명                |
| ------------------------ | -------------------- | ----------------- |
| `pobi,woni,jun`<br>`5`   | 전진 결과 출력 및 최종 우승자 표시 | 기본 입력 처리          |
| `pobi,woni,jun`<br>`go` | 예외 발생                | 시도 횟수에 숫자 외 문자 입력 |
| `pobiiiii,woni`<br>`7` | 예외 발생                | 이름이 5자 초과         |
| `,pobi,jun`<br>`2`       | 예외 발생                | 비어 있는 이름 입력       |
| `pobi,woni,jun`<br>`0`   | 예외 발생                | 시도 횟수 0 이하        |
| `pobi,jun`<br>`3`        | 우승자 1명 또는 공동 우승 출력   | 정상 동작       |
